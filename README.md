# Java Testing Exercises

A collection of Java and JUnit practice exercises maintained in Eclipse-style source files. The repository includes small examples involving calculations, arrays, grades, flight and hotel scenarios, and other introductory application logic.

## Current structure

- Java source files and corresponding test examples
- Some compiled `.class` files from earlier local builds
- No Maven or Gradle build configuration is currently present

## Important limitation

This is a learning collection rather than a single packaged application. The source files use different package declarations and a mix of JUnit styles, so the repository should not be expected to compile or run as one test suite without organizing the exercises and adding an explicit dependency/build setup.

## Recommended review

Start with an individual source and its matching test class. For a reproducible portfolio project, separate exercises into modules, remove generated class files from version control, add a Maven or Gradle build, and run tests from a clean checkout before reporting a passing result.
